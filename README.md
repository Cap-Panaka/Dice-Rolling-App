### ✨ Features
- **Instant Roll:** Random 1–6 dice outcomes with responsive state management.
- **Sleek Aesthetic:** Modern deep-purple gradient with smooth typography.
- **Cross-Platform:** Runs seamlessly on Web, Mobile, and Desktop.

### 🛠️ Built With
